Aurum Jewelry Manager

Offline Windows desktop app for goldsmith workshops

Private sourceElectronSQLitedecimal.jsoffline

Who it is for
Goldsmith workshops and wholesale jewellery makers, who run on paper ledgers and have no reliable internet in the workshop.
What it does
Per-store gold and money ledgers, the collection round, karigar boxes and job-workers, bag register, bills, expenses, a design catalogue with photos, ministry hallmark stamping, profit and loss, and the year-end statement.
The hard part
Gold is weighed to three decimal places and money must balance exactly, so every figure runs through decimal.js rather than floating point. One rounding error in a karigar's ledger is a real argument with a real person.
Built for no internet
The workshop floor has no reliable connection, so the whole application runs locally against an embedded SQLite database. It ships as a Windows installer with its own licence key-maker, signed and versioned, with a demo business built in.
What it covers
Two stores of gold and money, the collection round, karigar boxes and job-workers, the bag register, bills and expenses, a photo design catalogue, ministry hallmark stamping, live gold rate, profit and loss, and the year-end statement.

A commercial product in use by a working business, so the source and the installer are not public. Happy to walk through the architecture, the ledger model and the code in a meeting.

Flybook

TypeScriptWebAssemblykokoro-jspdf.jsPWA

What it does
Turns any PDF into an audiobook with natural neural voices, with highlights and notes, working offline and with no account.
The decision that shaped it
Every model runs on the device. Nothing is uploaded, so a private document stays private — the constraint that made the engineering hard and the privacy claim honest.
Tested
45 unit tests and 18 browser tests in Playwright, deployed by GitHub Actions.

Mr. Todo

ExpoReact NativeSupabaseVite

What it is
A marketplace where someone asks for a Personal Manager to get a task done — fix a tap, deep-clean a flat, take a parent to the bank — and where people apply to become one.
Three surfaces, one codebase
An Expo app running on iOS, Android and web; an admin dashboard for the team; and Supabase for the database, task actions and row-level security rules.
Security-adjacent
Every Personal Manager is ID-checked before approval, so the access model and the row-level rules are the part that matters most.

Studio

Private sourceLocal-firstAI pipelinein development

What it does
Takes anything from a 30-second clip to a multi-hour recording and produces long-form video, series, compilations, short-form cuts, captions and metadata.
The same principle as Flybook
All AI processing runs on your own machine by default. Nothing is sent anywhere.
How it is built
A Python backend doing the media and model work, a separate frontend, and a written architecture and decision log kept alongside the code rather than in someone's head.
Status
Early development, and the repository says so plainly: a status document separates what is implemented and verified from what is not started. Shipping an honest status beats shipping a claim.

Still being built, and the source is private while it is. Happy to demo it and talk through the pipeline in a meeting.

The thread running through all four: keep the user's data on the user's machine, and say plainly what is finished and what is not.

The security work is in casework and detections. Two published games and a few smaller tools live on my GitHub profile. Where a repository is private, I am glad to walk through the code in person.
