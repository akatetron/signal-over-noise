Case summaryIR-2026-0417

Five-stage intrusion on a Windows host

Telemetry. Sysmon and Windows Security event logs. No EDR, and no alert to start from.

Finding. Credentials were taken at stage four and never subsequently used.

Why it matters. That negative finding is the difference between isolating one host and declaring domain compromise.

  1. Stage 01DLL search-order hijackA signed binary loads mscoree.dll from ProgramData. Unsigned, version 0.0.0.0.T1574.001
  2. Stage 02PowerShell via CLR injectionThe .NET runtime loaded into a process with no managed code of its own.T1059.001
  3. Stage 03Process injectionA remote thread whose start address resolves to no loaded module.T1055
  4. Stage 04LSASS credential dumpingA handle to lsass.exe, CallTrace UNKNOWN. A .dmp lands twelve seconds later.T1003.001
  5. Stage 05PPID spoofingcmd.exe parented to the print spooler. The pairing is the signal.T1134.004
